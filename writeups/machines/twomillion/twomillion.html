About Target

TwoMillion is an Easy difficulty Linux box that was released to celebrate reaching 2 million users on HackTheBox. The box features an old version of the HackTheBox platform that includes the old hackable invite code. After hacking the invite code, an account can be created on the platform. The account can be used to enumerate various API endpoints, one of which can be used to elevate the user to an Administrator. With administrative access, the user can perform a command injection in the admin VPN generation endpoint, thus gaining a system shell. A .env file is found to contain database credentials and due to password reuse, the attacker can login as user admin on the box. The system kernel is found to be outdated and CVE-2023-0386 can be used to gain a root shell.

Phase 3 JS Deobfuscation

I deobfuscated the code using de4js, which produced the following readable JavaScript: 

function verifyInviteCode(code) {
    var formData = {
        "code": code
    };
    $.ajax({
        type: "POST",
        dataType: "json",
        data: formData,
        url: '/api/v1/invite/verify',
        success: function (response) {
            console.log(response)
        },
        error: function (response) {
            console.log(response)

Phase 7 OS Command Injection

I injected ;whoami; into the username field. My suspicion fell on the exec() or system() PHP functions, which are common in admin-only features and often lack proper sanitization.

For example, the vulnerable code probably looked something like this:

$username = $json->username;

exec("/usr/bin/cat /var/www/html/VPN/user/$username.ovpn");

The endpoint POST /api/v1/admin/vpn/generate was vulnerable, and OS Command Injection was performed successfully.

Reverse Shell via OS Command Injection (Base64 Bypass)

Since the application had restrictions that prevented special characters, I encoded the reverse shell payload in base64 to bypass this restriction.

I injected the payload into the username parameter, piping it to base64 -d | bash for decoding and execution:

Phase 9 OS Privilege Escalation

After gaining initial access as the admin user, I performed system enumeration to identify potential privilege escalation vectors.

I tried common privilege escalation techniques like SUID binaries, capabilities, sudo rights, and cron jobs—nothing worked. I then checked environment variables for PATH hijacking or sensitive variables, and I found a MAIL variable pointing to /var/mail/admin.

I checked the mail content and noticed that the admin had been warned to patch the kernel against an OverlayFS/FUSE vulnerability:

Kernel Version Enumeration

OS Version Enumeration

Critical Finding: The kernel was never updated, confirming that the administrator had ignored the security warning. Kernel version 5.15.70-051570-generic is vulnerable to CVE-2023-0386 (OverlayFS/FUSE local privilege escalation).

Exploit Execution

With the vulnerability confirmed, I proceeded to obtain a public POC exploit:

$ git clone https://github.com/sxlmnwb/CVE-2023-0386
$ cd CVE-2023-0386
$ make
$ ./fuse & & ./exp
