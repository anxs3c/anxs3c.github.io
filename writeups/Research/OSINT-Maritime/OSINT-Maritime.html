Introduction

Maritime OSINT is the systematic collection and analysis of publicly available information related to vessels, ports, maritime infrastructure, and crew members. Modern ships continuously transmit operational and positional data through systems including:
  • AIS — Automatic Identification System
  • Satellite Communications — Inmarsat, Iridium, VSAT
  • Maritime Radio Networks — VHF, MF/HF, NAVTEX

These data sources enable analysts to identify vessel movements, ownership structures, crew members, cargo patterns, and potential security vulnerabilities across the global maritime ecosystem.

Maritime OSINT Data Sources

  1. AIS Data — Position, heading, speed, voyage information
  2. Vessel Registries — IMO number, flag state, ownership
  3. Satellite Imagery — Port infrastructure, vessel positions
  4. Social Media — Crew profiles, company presence
  5. Shodan — Exposed maritime infrastructure
  6. Maritime Databases — Vessel specifications, history, incidents

AIS Architecture

The Automatic Identification System (AIS) is a maritime tracking system that uses transponders on vessels to broadcast position, speed, and navigational status. AIS operates on two dedicated VHF frequencies:

Channel Frequency Use
AIS 1161.975 MHz (CH 87B)Primary transmission channel
AIS 2162.025 MHz (CH 88B)Secondary transmission channel

AIS Message Types

Type Message Description
1, 2, 3Position ReportDynamic vessel position, speed, heading
5Static Voyage DataIMO, MMSI, vessel name, draft, destination
6, 12Addressed Binary MessageDirect communication between vessels
9SAR Aircraft PositionSearch and rescue aircraft position
18Class B Position ReportSmaller vessel position (reduced power)
24Class B Static DataStatic information for Class B vessels

Understanding these message types is critical for interpreting AIS data and identifying anomalies that may indicate intentional tampering or illicit activity.

Vessel Tracking Platforms

MarineTraffic — Technical Analysis

MarineTraffic aggregates AIS data from over 5,000 terrestrial receivers and satellite constellations to provide global vessel tracking coverage.

Data Collection Methodology

MarineTraffic collects and processes AIS data through:

  • Terrestrial AIS Receivers — Coastal stations (range up to 50 NM)
  • Satellite AIS — Global coverage (range unlimited)
  • Data Fusion — Integration of multiple data sources

Technical Features

Feature Description Technical Implementation
Real-time Tracking Live vessel positions WebSocket updates, 2-60 second intervals
Historical Voyage Data Route reconstruction PostgreSQL database with spatial indexing
Port Analysis Arrival/departure patterns Time-series aggregation and event correlation
Vessel Database Ship specifications Equasis, IMO, and regional registry integration

VesselFinder — Verification Framework

VesselFinder provides a secondary verification layer for AIS intelligence. Using multiple platforms enables:

  • Data Validation — Cross-referencing position reports
  • Anomaly Detection — Identifying AIS data discrepancies
  • Coverage Analysis — Identifying gaps in tracking coverage

Maritime Infrastructure Reconnaissance

Shodan — Technical Approach

Shodan enables investigators to discover internet-exposed maritime infrastructure through targeted queries: 

# Shodan search queries for maritime infrastructure

# Exposed SATCOM terminals
http.title:"Inmarsat"

# Vessel management systems
http.title:"Vessel Management" OR "Fleet Management"

# Exposed RDP services
port:3389 AND "ship" OR "maritime" OR "vessel"

# Satellite terminal management
http.title:"VSAT" OR "Satellite Terminal"

# Navigation systems
port:8080 AND "ECDIS" OR "navigation"

Vessel Identification Systems

Unique Identification Codes for Vessels (UICVs) allow analysts to reliably track ships across multiple maritime databases throughout their operational lifetime.

Identifier Hierarchy

Identifier Format Persistence Use Case
IMO Number 7-digit (IMO 1234567) Lifetime Universal vessel identification
MMSI 9-digit (MIDXXXXXX) Long-term AIS and digital maritime transmissions
IRCS 4-5 alphanumeric Long-term Radio communication at sea
National Registration Variable Varies Flag state registry
RFMO ID Variable Varies Fisheries management monitoring

These identifiers allow investigators to track vessels even when ship names, ownership, or flag registrations change, making them essential for maritime OSINT investigations.

Port Intelligence and Analysis

Ports represent critical nodes within global supply chains and are often exploited for smuggling and illicit logistics operations.

Analytical Framework

Port Intelligence Methodology

  2. Port Infrastructure Assessment — Capabilities, capacity, security posture
  3. Cargo Logistics Analysis — Identifying unusual cargo patterns
  4. Historical Satellite Imagery — Time-series port activity analysis
  5. Personnel Profiling — Port officials, contractors, security personnel

Investigation Framework

Maritime OSINT Investigation Framework

This structured methodology ensures comprehensive intelligence gathering and analysis.

Phase 1: Target Identification

  • Identify vessel name, IMO number, or MMSI
  • Gather basic vessel specifications
  • Determine flag state and ownership

Phase 2: Historical Analysis

  • Reconstruct voyage timeline
  • Identify previous ports of call
  • Detect route anomalies or AIS gaps
  • Analyze pattern of port visits

Phase 3: Association Mapping

  • Crew profiling and personnel identification
  • Corporate structure analysis
  • Vessel ownership and operator mapping
  • Network analysis of related entities

Phase 4: Infrastructure Analysis

  • Port visit patterns and durations
  • Satellite imagery analysis
  • Shodan reconnaissance
  • Security vulnerability assessment

Phase 5: Reporting

  • Structured intelligence report
  • Key findings and indicators
  • Security recommendations

Technical Case Study

  4. Step 4 — Infrastructure Analysis
    • Port visit patterns analyzed

    • Shodan identified exposed maritime systems
  5. Step 5 — Reporting
    • Comprehensive intelligence report produced
    • Indicators of potential illicit activity identified
    • Security recommendations provided
