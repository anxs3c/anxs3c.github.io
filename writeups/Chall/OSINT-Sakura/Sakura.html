Challenge Overview

Challenge Category: Open Source Intelligence (OSINT)
Challenge Name: Sakura

Scenario: As the OSINT team, we found ourselves victims of a cyber attack. However, due to the attacker's mistake, they left an image that our forensic team discovered. Now we must determine who the attacker is.

The attacker left a picture at this website. My objective was to analyze the website's source code and the picture to gather information about the attacker.

At first, I visited the website and saw a picture with pink and white colors, containing the text "You've Been Pwned" and binary code in the background.

Key Takeaways

  • Metadata is critical — Always analyze file metadata for hidden information
  • Username reuse across platforms enables comprehensive profiling
  • Git commit history can reveal sensitive information that was later removed
  • Cryptocurrency blockchains are public ledgers — all transactions are traceable
  • WiFi SSIDs and BSSIDs can be used for physical location tracking
  • PGP keys contain user identity information that can be extracted
